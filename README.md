# FitFlex 

FitFlex is a Flutter-based mobile application designed to help users customize their meal plans, track fitness goals, and monitor running activities. The app features a sleek, dark-themed UI with blue and green accents, providing an intuitive experience for health and fitness enthusiasts.

## Features

- **Edit Meal Plan:** Customize meal plans with height range, weight range, body fitness level, attachments, food title, description, and meal options (Breakfast, Lunch, Dinner).
- **Choose Your Goal:** Select from various goals like Run, Stats, Diets, Leaderboard, Medal, and Share.
- **Run Screen:** View previous run recaps, set distance goals, and start/pause/finish runs.
- **Ongoing Run:** Real-time tracking of time elapsed, distance traversed, and flights climbed.
- **Statistic Screen:** Display weekly runs, history, and growth metrics.
- **Leaderboard Screen:** Show social and area-based rankings with user positions and distances.
- **Onboarding Screen:** Welcome screen, login, sign-up, and password update flows.
- **Medals Screen:** Track achievements with unlocked and locked medals.
- **Share Screen:** Share run recaps with distance traveled, time taken, and leaderboard position.
- **Diets Plan Screen:** Browse personalized and suggested meal plans, favorites, recipe cards, and nutritional details.

   ```bash

4. Install dependencies:

5. Run the app on an emulator or device:
   ```bash
   flutter run

## Usage
- Sign up or log in to access personalized features.
- Edit your meal plan with custom goals and upload attachments.
- Choose a fitness goal and track your runs in real-time.
